    • CreatejsText

    Class CreatejsText

    inherited createjs.Text

    text/font/color/textAlign/lineHeight/lineWidth/mask are all plain data properties on the real createjs.Text/DisplayObject, but this wrapper must intercept get/set on each to route the assigned value into the Pixi mirror. See the class-level comment on CreatejsShape for why a prototype accessor safely intercepts them despite TS2611/TS2416.
